|  Name | Active Level | Description | Relevant Protocols  |
| --- | --- | --- | --- |
|  MacCLKPHYMode [3:0] | N/A | Selects the protocol associated with this MacCLK lane: 0 - PCIe 1 - USB 2 - SATA 3 - DisplayPort 4 - Reserved 5 - Reserved 6 - Reserved 7 - USB4 All other reserved. This signal is asynchronous and is permitted to change only during MacCLKReset# assertion. The MAC must ensure this signal is valid at MacCLKReset# deassertion. | PCIe, SATA, USB, DisplayPort, USB4  |
|  MacCLKRate[4:0] | N/A | Selects the rate of the MacCLK. This uses the following encoding definitions: 0-30: Uses the same encoding definitions as PCLK Rate. 31: Vendor specific override This signal is asynchronous and is permitted to change during MacCLKReset# assertion. The MAC must ensure this signal is at a valid value at MacCLKReset# deassertion. When MacCLKReset# is deasserted, this signal is permitted to change only when MacCLKReq and MacCLKAck are deasserted. The MAC must ensure MacCLKRate is stable before MacCLKReq asserts. | PCIe, SATA, USB, DisplayPort, USB4  |
|  MacCLKReq | High | The MAC sets this signal to "1" to request the MacCLK to run and sets this signal to "0" to request the MacCLK to stop. When this signal is asserted, the PHY is required to start the MacCLK and then to subsequently assert MacCLKAck to indicate the MacCLK is valid and running at the desired rate. When this signal is deasserted, the PHY is required to stop the MacCLK and deassert MacCLKAck before or after MacCLK is stopped. This signal is asynchronous. The MAC must ensure this signal is valid at MacCLKReset# deassertion. This signal defaults to "0" when MacCLKReset# deasserts. | PCIe, SATA, USB, DisplayPort, USB4  |
|  MacCLKSSCEnable | High | The MAC sets this to signal to "1" to request SSC to be enabled on the MacCLK. This signal is set to "0" to request SSC to be disabled on the MacCLK. This signal is asynchronous and is permitted to change during MacCLKReset# assertion. The MAC must ensure this signal is at a valid value at MacCLKReset# deassertion. MacCLKSSCEnable is permitted to be dynamically asserted or deasserted while MacCLK is running. | PCIe, SATA, USB, DisplayPort, USB4  |
|  MacCLKReset# | Low | Resets the MacCLK lane state. This signal is asynchronous and is permitted to assert at any time regardless of PHY state. | PCIe, SATA, USB, DisplayPort, USB4  |
