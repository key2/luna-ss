|  [7:0] | 0h | Level | PCIe (optional) and USB4 | **Error Count[7:0]:** This field is only required if errors do not happen in the data stream and thus an independent error sampler is implemented in the PHY. This field is used by the PHY to report actual bit errors to the MAC. This field can increment only when "Start Margin" is asserted. This field only resets on a PIPE reset or when the MAC writes to the "Error Count Reset" bit in the Rx Margin Control1 register. If used, this field must be updated by the PHY every time the associated value changes; implementations may collapse multiple updates into a single write to avoid creating a backlog of writes. For PCIe, the upper two bits are reserved and only the lower 6 bits are utilized. For USB4, the Error Count is 16 bits, refer to RX Margin Status3 in Section 7.2.8 for upper 8 bits.  |
