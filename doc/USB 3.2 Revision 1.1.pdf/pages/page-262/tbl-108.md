|  2 | 0:12 | **LDM Sequence Number (LDMS).** This field identifies the sequence number of a LDM Exchange. The value of this field shall be set by the Requester in a LDM Request, and returned by Responder in the associated LDM Response. This value shall be incremented on each Exchange initiated by the Requester.  |
