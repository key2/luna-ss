### NOTE

This specification includes features to support SSIC capabilities, such as asymmetric link speeds and multiple lanes.

The Enhanced SuperSpeed bus does not support Asymmetric link speeds. An Enhanced SuperSpeed device shall only set the **Sublink Type** to Symmetric.
