|  Bit | Description  |
| --- | --- |
|  0 | Connect Status Change (C_PORT_CONNECTION): Indicates a change has occurred in the port's Current Connect Status. The hub device sets this field as described in Section 10.3.1. **Value****Meaning** 0 No change has occurred to Current Connect status 1 Current Connect status has changed  |
|  1-2 | Reserved  |
|  3 | Over-Current Indicator Change (C_PORT_OVER_CURRENT): This field applies only to hubs that report over-current conditions on a per-port basis (as reported in the hub descriptor). **Value****Meaning** 0 No change has occurred to Over-Current Indicator 1 Over-Current Indicator has changed If the hub does not report over-current on a per-port basis, then this field is always zero.  |
|  4 | Reset Change (C_PORT_RESET): This field is set when reset processing for any type of reset on this port is complete. **Value****Meaning** 0 No change 1 Reset complete  |
|  5 | BH Reset Change (C_BH_PORT_RESET): This field is set when a warm reset processing on this port is complete **Value****Meaning** 0 No change 1 Reset complete  |
